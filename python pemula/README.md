🐍 Python Pemula

Repository ini berisi dokumentasi dan latihan pembelajaran Python Dasar dari awal hingga memahami konsep-konsep dasar pemrograman Python.

📚 Materi yang Dipelajari

Berikut materi yang sudah dipelajari dan dikerjakan:

1. Hallo Python – Pengenalan dan program pertama Python.
2. Python Variables and Data Types – Mengenal variabel dan tipe data.
3. Learn Python Operators – Mempelajari operator dalam Python.
4. Python If Else Conditions – Memahami percabangan kondisi.
5. Python Loops – Mempelajari perulangan.
6. Python Dictionaries – Mengenal struktur data dictionary.
7. Python Functions – Membuat dan menggunakan fungsi.
8. Learn Python Classes and Objects – Mengenal konsep class dan object.
9. PIP and Virtual Environments – Mengenal pengelolaan package dan lingkungan virtual Python.

🎯 Tujuan Pembelajaran

- Memahami dasar-dasar bahasa pemrograman Python.
- Mengenal sintaks dan struktur kode Python.
- Melatih logika pemrograman.
- Mempelajari fungsi dan struktur data.
- Memahami konsep dasar Object-Oriented Programming (OOP).
- Mengenal penggunaan PIP dan Virtual Environment.

🛠️ Tools yang Digunakan

- Python
- Visual Studio Code
- Git
- GitHub

🚀 Menjalankan Program

Pastikan Python sudah terinstal di komputer.

Jalankan file Python melalui terminal:

python nama_file.py
